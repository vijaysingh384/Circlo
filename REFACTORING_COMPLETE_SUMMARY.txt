INTERVIEW TALKING POINTS:

Architecture:
"I built Circlo with a simple client-server architecture using React and 
Node.js. I intentionally avoided over-engineering with Redux or complex 
patterns to keep it maintainable and easy to explain."

Real-Time:
"I used Socket.IO for real-time photo updates. When someone uploads a 
photo, it instantly appears for all users in that event room. I 
implemented room-based events to ensure updates only go to relevant users."

Security:
"I validate files using magic numbers, not just extensions, to prevent 
file type spoofing. I also sanitize filenames to prevent path traversal 
attacks and implement session-based permissions."

Code Quality:
"I use TypeScript throughout for type safety, custom hooks to encapsulate 
logic, and utility functions for reusable code. The project structure is 
clean with clear separation of concerns."

Scalability:
"The current implementation uses local storage, but it's designed to 
easily switch to cloud storage like S3 or Cloudflare R2. I also 
implemented auto-cleanup to prevent storage bloat."
